# Práctica de Dokploy

Universidad del Quindío  
Ingeniería de Sistemas y Computación  
Administración de Infraestructura de TI

## Descripción

Aplicación web desarrollada con Node.js y Express.js
para realizar una práctica de administración de contenedores
y despliegue de aplicaciones utilizando Dokploy.

## Tecnologías

- Node.js
- Express.js
- Docker
- Docker Swarm
- Dokploy
- GitHub

## Rutas disponibles

- `/`: Información general de la aplicación.
- `/health`: Estado de funcionamiento.
- `/info`: Información del entorno de ejecución.

## Ejecución local

Instalar dependencias:

npm install

Iniciar la aplicación:

npm start

## Despliegue

La aplicación será desplegada mediante Dokploy
utilizando integración con un repositorio de GitHub.
